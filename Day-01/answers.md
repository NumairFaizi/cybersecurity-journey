2. What is a vulnerability?

=>

Vulnerability in simple words means weakness. In cyber security it means the threats and weakpoints of a website or a digital system.

3. What's the difference between a threat and a vulnerability?

=>

Threats means external or internal dangers. while the Vulnerability is a gap or security lapse.

9. Scenario

A website allows:

GET /api/user/100

A logged-in user changes it to:

GET /api/user/101

and can see another user's information.

What type of security problem does this demonstrate?
=>

This scenario demonstrates a Broken Object Level Authorization (BOLA) vulnerability, which is also commonly referred to as Insecure Direct Object References (IDOR).
